## О чём эта программа?!

Это программа является кодировщиком символов в азбуку Морзе и из азбуки Морзе в символы.
То есть поддерживает как encoding так и decoding.
Указание действия происходит в параметрах при запуске (-e/--encoding для encoding действия или -d/--decoding соответственно) или при запуске ПО вас попросят ввести тип действия.

Программа поддерживает только цифры, некоторые спецзнаки, русские симф. Пробелы между словами ставятся знаком "/".
